## ⚡ 问题 → 解决方案 → 对比

### 你的问题

每天，数百万人在重复同一个动作：

**找信息 → 换窗口 → 填信息 → 再换窗口 → 重复50次...**

研究表明，**每次窗口切换需要15-25秒才能恢复注意力**。一个看似10分钟的任务，实际要耗25分钟——其中15分钟被浪费在切换上。你的注意力在碎片化。

### 我们的解决方案

```
❌ 传统：找→切→填 | 找→切→填 | 找→切→填  [断裂的工作流]
✅ PickPaste：找→找→找 | 一次切换 | 填→填→填  [连续的流]
```

**核心逻辑**：先集中收集所有信息，再集中完成填写。不打断你的工作流。

## 🚀 快速开始 & 安装 & 配置

### ⚡ 30秒启动

1. **下载** [`PickPaste.exe`](bin/PickPaste.exe)
2. **双击运行**
3. **完成** — 立即可用

就这样。不需要安装、配置、重启。

### 🎮 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Alt + C` | 收集当前剪贴板 |
| `Ctrl + Alt + V` | 粘贴下一项 |
| `Ctrl + Alt + X` | 清空队列 |
| `Ctrl + Alt + Q` | 查看队列状态 |

支持鼠标侧键（XButton1/XButton2）做同样的事。

### ⚙️ 自定义配置（可选）

编辑 `config.ini`：

```ini
[Hotkeys]
EnableKeyboard=true    # 键盘快捷键
EnableXButton=true     # 鼠标侧键
```

保存即生效，无需重启。

### 📋 系统要求

| 项目 | 要求 |
|------|------|
